01¿Qué es una ROI?

Una Region of Interest es un subconjunto delimitado del espacio de una imagen sobre el que se concentra el procesamiento computacional. En lugar de aplicar algoritmos costosos sobre cada píxel del frame completo, se define una ventana — rectangular, circular, poligonal o basada en máscara — dentro de la cual se realizan las operaciones.

El concepto tiene raíces en la visión humana: el sistema visual periférico humano actúa como prefilter de baja resolución que dirige la fóvea (zona de máxima resolución) a la región relevante. En sistemas de visión artificial, la ROI reproduce ese mecanismo de atención selectiva.

🎯

Eficiencia computacional

Reducir el área procesada de 1080×1920 a 200×200 baja el trabajo por factor ~100×. El coste de procesamiento escala con los píxeles analizados.

⚡

Reducción de latencia

Menos píxeles = menos ciclos de CPU/GPU = menor tiempo de inferencia. Crítico en aplicaciones real-time (≤33ms por frame a 30fps).

📐

Mayor precisión local

Un modelo que procesa un crop ampliado de la cara detecta mejor microexpresiones que uno que procesa el frame completo con la cara pequeña.

🧠

Contexto semántico

Permite alimentar modelos especializados con el dato que corresponde: el modelo de iris recibe solo el crop del ojo, no toda la cara.

🔁

Integración con tracking

La ROI se propaga entre frames siguiendo el objeto, evitando redetecciones completas. El tracker mantiene la ventana alineada con el sujeto.

💾

Menos transferencia de datos

En pipelines con aceleradores (GPU, NPU, EdgeTPU), transferir solo el ROI reduce el cuello de botella en el bus de datos.

02Tipos de ROI

🔲 ROI Rectangular (Bounding Box)

La más común. Definida por coordenadas (x, y, w, h) o (x1, y1, x2, y2). Fácil de extraer con slicing NumPy. OpenCV y la mayoría de detectores la usan como salida nativa.

# Extracción directa
roi = frame[y1:y2, x1:x2]

⬡ ROI Poligonal

Definida por un polígono convexo o cóncavo. Se usa cuando el área de interés no es rectangular: zonas de tráfico, siluetas corporales, áreas de seguridad. Requiere máscara.

pts = np.array([[x1,y1],[x2,y2],[x3,y3]])
mask = np.zeros_like(frame)
cv2.fillPoly(mask, [pts], (255,255,255))
roi = cv2.bitwise_and(frame, mask)

⭕ ROI Circular / Elíptica

Para iris, pupilas, objetos circulares. Se define por centro y radio o semiejes. Generalmente se convierte a máscara binaria antes de procesar.

mask = np.zeros(frame.shape[:2], dtype='uint8')
cv2.circle(mask, (cx, cy), r, 255, -1)
roi = cv2.bitwise_and(frame, frame, mask=mask)

🎭 ROI por Máscara de Segmentación

La ROI más precisa: cada píxel se clasifica como dentro/fuera. Producida por modelos de segmentación (SAM, DeepLab). Coste computacional alto, pero máxima fidelidad espacial.

# mask es salida binaria del modelo
roi = np.zeros_like(frame)
roi[mask > 0.5] = frame[mask > 0.5]

03Geometría y Transformaciones

Sistemas de coordenadas

En procesamiento de imágenes coexisten tres espacios de coordenadas que hay que mantener correctamente sincronizados:

🖼️ Espacio Imagen (absoluto)

Coordenadas en píxeles desde la esquina superior izquierda. Rango: [0, W) × [0, H). El eje Y crece hacia abajo. Origen en (0,0).

x ∈ [0, W-1]
y ∈ [0, H-1]

📦 Espacio ROI (relativo)

Coordenadas locales dentro del crop extraído. Origen en la esquina superior izquierda del bounding box. Rango: [0, roi_w) × [0, roi_h).

x_roi = x_img - x1
y_roi = y_img - y1

📊 Espacio Normalizado

MediaPipe y redes modernas emiten coordenadas en [0,1]. Fáciles de escalar a cualquier resolución, pero hay que reescalar al espacio imagen para visualizar.

x_px = x_norm × W
y_px = y_norm × H

Transformación ROI → Frame original

Cuando se procesan landmarks dentro de un ROI, las coordenadas deben reescalarse al espacio del frame completo. El proceso es una transformación afín:

def roi_to_frame(lm_x, lm_y, roi_bbox, roi_size):
    """
    lm_x, lm_y   : coords normalizadas [0,1] dentro del ROI
    roi_bbox      : (x1, y1, x2, y2) del ROI en el frame
    roi_size      : (roi_w, roi_h) del crop redimensionado
    """
    x1, y1, x2, y2 = roi_bbox
    roi_w = x2 - x1
    roi_h = y2 - y1

    # Escalar de espacio normalizado a píxeles del ROI
    x_roi = lm_x * roi_w
    y_roi = lm_y * roi_h

    # Trasladar al espacio del frame completo
    x_frame = x_roi + x1
    y_frame = y_roi + y1

    return int(x_frame), int(y_frame)

# Vectorizado con NumPy para múltiples puntos
def batch_roi_to_frame(landmarks_norm, roi_bbox):
    x1, y1, x2, y2 = roi_bbox
    scale = np.array([x2-x1, y2-y1])
    offset = np.array([x1, y1])
    return (landmarks_norm * scale + offset).astype(int)

Margen de expansión (padding)

Un ROI demasiado ajustado pierde contexto (orejas, contorno del cráneo). Un ROI demasiado grande desperdicia cómputo. La práctica estándar es expandir el bounding box con un factor de margen:

def expand_bbox(x1, y1, x2, y2, margin=0.2, img_w=1920, img_h=1080):
    """
    margin=0.2 añade 20% del tamaño del bbox en cada lado.
    Se clampea para no salir del frame.
    """
    w = x2 - x1
    h = y2 - y1
    dx = int(w * margin)
    dy = int(h * margin)

    x1_new = max(0,     x1 - dx)
    y1_new = max(0,     y1 - dy)
    x2_new = min(img_w, x2 + dx)
    y2_new = min(img_h, y2 + dy)

    return x1_new, y1_new, x2_new, y2_new

# Márgenes recomendados por tarea:
# Cara completa:      margin = 0.15 – 0.25
# Solo ojo (iris):    margin = 0.30 – 0.50
# Vehículo en calle: margin = 0.05 – 0.10
💡

Regla práctica: Para detección facial, un margen del 20–25% en cada lado garantiza que ningún landmark quede en el borde del crop, lo que degrada la precisión del modelo dramáticamente. Para el submodelo de iris de MediaPipe, el margen debe ser ≥40% del tamaño del ojo.

04Extracción y Preprocesamiento

Slicing NumPy — la operación fundamental

En OpenCV/NumPy, una imagen es un array 3D (H, W, C). Extraer un ROI es simplemente un slice. Importante: el slice devuelve una vista (no copia), eficiente en memoria pero peligroso si se modifica.

import cv2
import numpy as np

# Vista — no copia datos (rápido)
roi_view = frame[y1:y2, x1:x2]          # modificar esto afecta frame

# Copia — independiente del frame original
roi_copy = frame[y1:y2, x1:x2].copy()   # safe para procesamiento asíncrono

# Redimensionar al tamaño que espera el modelo
MODEL_INPUT = (192, 192)  # MediaPipe Face Landmark
roi_resized = cv2.resize(roi_copy, MODEL_INPUT,
                          interpolation=cv2.INTER_LINEAR)

# Normalizar a [0,1] float32
roi_float = roi_resized.astype(np.float32) / 255.0

# Añadir dimensión batch: (1, H, W, C)
roi_batch = np.expand_dims(roi_float, axis=0)

Manejo de bordes — casos límite

def safe_crop(frame, x1, y1, x2, y2):
    """
    Maneja ROIs que salen parcialmente del frame.
    Rellena las áreas externas con negro (o con mean del ROI).
    """
    h, w = frame.shape[:2]

    # Coordenadas clampeadas al frame
    cx1, cy1 = max(0,x1), max(0,y1)
    cx2, cy2 = min(w,x2), min(h,y2)

    # Crear canvas del tamaño original del ROI solicitado
    roi_w, roi_h = x2-x1, y2-y1
    canvas = np.zeros((roi_h, roi_w, frame.shape[2]), dtype=frame.dtype)

    # Offset donde pegar el crop válido dentro del canvas
    paste_x1 = cx1 - x1
    paste_y1 = cy1 - y1
    crop = frame[cy1:cy2, cx1:cx2]
    canvas[paste_y1:paste_y1+crop.shape[0], paste_x1:paste_x1+crop.shape[1]] = crop

    return canvas

Estrategia híbrida detect → track → redetect

class ROITracker:
    """
    Detecta en frame 0, luego trackea N frames,
    luego redetecta para corregir drift acumulado.
    """
    def __init__(self, detector, redetect_every=15, margin=0.2):
        self.detector = detector
        self.redetect_every = redetect_every
        self.margin = margin
        self.frame_count = 0
        self.roi_bbox = None
        self.tracker = None
        self.confidence = 1.0

    def update(self, frame):
        h, w = frame.shape[:2]
        needs_detect = (
            self.roi_bbox is None                             # primer frame
            or self.frame_count % self.redetect_every == 0   # periódica
            or self.confidence < 0.4                          # tracker perdió
        )

        if needs_detect:
            # Detección sobre frame completo
            faces = self.detector.detect(frame)
            if not faces:
                return None
            self.roi_bbox = expand_bbox(*faces[0]['bbox'],
                                         margin=self.margin, img_w=w, img_h=h)
            # Reiniciar tracker en la nueva posición
            self.tracker = cv2.TrackerKCF_create()
            x1,y1,x2,y2 = self.roi_bbox
            self.tracker.init(frame, (x1, y1, x2-x1, y2-y1))
        else:
            # Solo tracking — barato
            ok, (tx, ty, tw, th) = self.tracker.update(frame)
            self.confidence = 1.0 if ok else 0.0
            if ok:
                self.roi_bbox = expand_bbox(
                    tx, ty, tx+tw, ty+th,
                    margin=self.margin, img_w=w, img_h=h
                )

        self.frame_count += 1
        return self.roi_bbox
⚠️

Drift acumulativo: Los trackers como KCF/CSRT acumulan error frame a frame. Sin redetección periódica, el ROI se desplaza y el modelo recibe un crop incorrecto. El intervalo óptimo de redetección depende de la velocidad de movimiento esperada: para cabeza quieta, K=30; para movimiento rápido, K=5–10.

ROI multi-escala para robustez

def multi_scale_roi(frame, bbox, scales=[0.8, 1.0, 1.2]):
    """
    Procesa el mismo ROI a múltiples escalas y combina.
    Útil cuando el sujeto puede estar parcialmente fuera del ROI esperado.
    """
    results = []
    x1,y1,x2,y2 = bbox
    cx, cy = (x1+x2)//2, (y1+y2)//2
    w, h = x2-x1, y2-y1

    for s in scales:
        sw, sh = int(w*s/2), int(h*s/2)
        scaled_bbox = (cx-sw, cy-sh, cx+sw, cy+sh)
        roi = safe_crop(frame, *scaled_bbox)
        results.append((s, roi, scaled_bbox))

    return results  # procesar cada uno y tomar la predicción de mayor confianza

06Algoritmos de Tracking para ROI Dinámico

🔵 KCF — Kernelized Correlation Filter

Basado en filtros de correlación en dominio frecuencial. Eficiente en CPU, excelente para objetos que se mueven suavemente. No maneja bien oclusión ni cambios bruscos de escala.

Velocidad: ~0.5ms/frame
Precisión: media
cv2.TrackerKCF_create()

🟢 CSRT — Channel and Spatial Reliability

Extensión de KCF con mapa de confiabilidad espacial. Más robusto ante cambios de escala y deformación. ~3× más lento que KCF pero mejor precisión.

Velocidad: ~2ms/frame
Precisión: alta
cv2.TrackerCSRT_create()

🟠 Kalman Filter

Modelo dinámico lineal que predice la posición futura basado en velocidad y aceleración. Ideal para combinar con detectores: el Kalman predice, el detector corrige.

Velocidad: ~0.1ms/frame
Precisión: depende del modelo
cv2.KalmanFilter()

🔴 ByteTrack / DeepSORT

Trackers multi-objeto basados en Hungarian algorithm + apariencia (DeepSORT) o solo IoU (ByteTrack). Para múltiples sujetos simultáneos. Más complejo pero maneja reid y oclusión.

Velocidad: ~5–15ms/frame
Precisión: muy alta
pip install bytetracker

Kalman Filter para predicción de ROI

import cv2
import numpy as np

class KalmanROI:
    """
    Estado: [x, y, vx, vy]  (posición centro + velocidad)
    Medición: [x, y]        (centro del bbox detectado)
    """
    def __init__(self):
        self.kf = cv2.KalmanFilter(4, 2)  # 4 estados, 2 medidas

        # Matriz de transición: posición += velocidad
        self.kf.transitionMatrix = np.array([
            [1,0,1,0],
            [0,1,0,1],
            [0,0,1,0],
            [0,0,0,1]], dtype=np.float32)

        # Matriz de medición: observamos solo x, y
        self.kf.measurementMatrix = np.array([
            [1,0,0,0],
            [0,1,0,0]], dtype=np.float32)

        self.kf.processNoiseCov     = np.eye(4, dtype=np.float32) * 0.03
        self.kf.measurementNoiseCov = np.eye(2, dtype=np.float32) * 1.0

    def predict(self):
        return self.kf.predict()[:2]  # posición predicha (x, y)

    def correct(self, x, y):
        measurement = np.array([[np.float32(x)],
                                   [np.float32(y)]])
        return self.kf.correct(measurement)

# Uso en pipeline:
kf = KalmanROI()
for frame in video_stream:
    pred_cx, pred_cy = kf.predict()     # usar para el ROI del frame actual
    if frame_count % K == 0:            # cada K frames: detectar y corregir
        detected_cx, detected_cy = run_detector(frame)
        kf.correct(detected_cx, detected_cy)

08ROI en RetinaFace

RetinaFace no tiene sistema de ROI/tracking nativo. Hay que implementarlo externamente. La ganancia es enorme porque su backbone FPN es costoso en el frame completo.

Arquitectura FPN y por qué el ROI ayuda tanto

RetinaFace usa una Feature Pyramid Network con anchors a múltiples escalas. El coste computacional escala con el área de la imagen procesada:

FLOPs ≈ O(H × W × C²)
ROI de 30% de área → ~0.3× los FLOPs del frame completo 
from retinaface import RetinaFace
import cv2, numpy as np

class RetinaFaceROI:
    def __init__(self, redetect_interval=15, margin=0.25):
        self.interval = redetect_interval
        self.margin   = margin
        self.roi_bbox = None
        self.tracker  = None
        self.n = 0

    def _detect_in_roi(self, frame, roi_bbox):
        x1,y1,x2,y2 = roi_bbox
        crop = frame[y1:y2, x1:x2]
        faces = RetinaFace.detect_faces(crop)
        if not isinstance(faces, dict):
            return None

        # Traducir landmarks al espacio frame
        best = faces[list(faces.keys())[0]]
        # Landmarks: right_eye, left_eye, nose, mouth_right, mouth_left
        lm_roi = best['landmarks']
        lm_frame = {k: (v[0]+x1, v[1]+y1) for k,v in lm_roi.items()}

        # BBox también traducida
        fb = best['facial_area']
        bbox_frame = (fb[0]+x1, fb[1]+y1, fb[2]+x1, fb[3]+y1)

        return {'bbox': bbox_frame, 'landmarks': lm_frame,
                'score': best['score']}

    def process(self, frame):
        h, w = frame.shape[:2]

        if self.roi_bbox is None or self.n % self.interval == 0:
            # Detección completa
            faces = RetinaFace.detect_faces(frame)
            if not isinstance(faces, dict):
                self.n += 1; return None
            best = faces[list(faces.keys())[0]]
            fa = best['facial_area']
            self.roi_bbox = expand_bbox(fa[0],fa[1],fa[2],fa[3],
                                          self.margin, w, h)
            self.tracker = cv2.TrackerCSRT_create()
            x1,y1,x2,y2 = self.roi_bbox
            self.tracker.init(frame, (x1,y1,x2-x1,y2-y1))
            result = self._detect_in_roi(frame, self.roi_bbox)
        else:
            # Tracking barato + detección en ROI
            ok, (tx,ty,tw,th) = self.tracker.update(frame)
            if ok:
                self.roi_bbox = expand_bbox(tx,ty,tx+tw,ty+th,self.margin,w,h)
            result = self._detect_in_roi(frame, self.roi_bbox)

        self.n += 1
        return result
